## Introduction

In [Introduction to Algebraic Geometry - 2](https://antoniococan.github.io/blogcocan/posts/introalgebraicgeometry2/), I introduced the basic objects of study, namely, affine algebraic sets which are defined as the common zero sets of polynomials. We then saw that different collections of polynomials can define the same vanishing set. This led us to enlarge sets of polynomials to ideals. An ideal is simply an additive subgroup with the additional property that it is stable under multiplication by the ambient ring. 

Furthermore, we arrived at Hilbert's Basis Theorem which states that every ideal in a polynomial ring is finitely generated. Rings with this property are called Noetherian. We then saw that even though a priori a common zero set is not given by solving finitely many polynomials, it follows by Hilbert's Basis Theorem that any such set of polynomials is generated by finitely many polynomials and their zero sets agree.

:::theorem{title="Extreme Value Theorem"}

Every convergent sequence is bounded.

Every continuous function on a compact metric space is bounded.

:::definition{title="Metric Space"}

A metric space is a set equipped with a distance function.

:::

The real numbers with the usual distance form a metric space.

:::
