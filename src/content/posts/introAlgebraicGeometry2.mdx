## Affine Algebraic Sets

In [Introduction to Algebraic Geometry - 1](https://antoniococan.github.io/blogcocan/posts/introalgebraicgeometry1/), 

:::definition{title="Affine algebraic sets"}

Let $S \subseteq k[x_1, \ldots, x_n]$ be a set of polynomials. We define the *zero set* (or *vanishing set*) $\mathbb{V}(S)$ of $S$ by

$$
\mathbb{V}(S) := \{ a \in \mathbb{A}^{n}_{k} : f(a) = 0, \forall f \in S \}.
$$

A subset $X \subseteq \mathbb{A}^{n}_{k}$ is called an *affine algebraic set* if $X = \mathbb{V}(S)$ for some $S \subseteq k[x_1, \ldots, x_n]$.

:::

The following proposition summarizes how affine algebraic sets behave under set-theoretic operations. The first statement says that if the set of polynomials is larger, the set
of common zeros will be smaller. The second statement asserts that an arbitrary intersection of affine varieties is again an affine variety. The last statement says that a finite union of affine varieties is an affine variety

:::proposition

1. If $S_1 \subseteq S_2$, then $\mathbb{V}(S_1) \supseteq \mathbb{V}(S_2)$.
2. For subsets $S_i \subseteq k[x_1, \ldots, x_n]$ we have that

$$
\bigcap_{i \in I} \mathbb{V}(S_i) = \mathbb{V} \Big ( \bigcup_{i \in I} S_i \Big ).
$$

3. For any two subsets $S_1, S_2 \subseteq k[x_1, \ldots, x_n]$ we have that

$$
\mathbb{V}(S_1) \cap \mathbb{V}(S_2) = \mathbb{V}(S_1 \cdot S_2),
$$

where the product $S_1 \cdot S_2$ is defined by

$$
S_1 \cdot S_2 := \{ f \cdot g : f \in S_1, g \in S_2 \}.
$$

:::

:::

## Summary

:::theorem{title="Extreme Value Theorem"}

Every continuous function on a compact space is bounded.

:::

:::lemma{title="Boundedness of Convergent Sequences"}

Every convergent sequence is bounded.

:::

:::corollary{title="Boundedness"}

Every continuous function on a compact metric space is bounded.

:::

:::proposition{title="Uniqueness of Limits"}

A convergent sequence in a metric space has a unique limit.

:::

:::definition{title="Metric Space"}

A metric space is a set equipped with a distance function.

:::

:::example{title="The Real Numbers"}

The real numbers with the usual distance form a metric space.

:::

:::remark{title="Completeness"}

Not every metric space is complete.
