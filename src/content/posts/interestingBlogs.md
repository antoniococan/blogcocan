This post is a collection of mathematical blogs and programming blogs -- mostly game programming and graphics programming. Some of these are not blogs but documentation pages or places where to learn that specific skill. This post is also a place for me to keep my resources structured since I am a very forgetful person when it comes to these things and I want to minimize the search time.

## Mathematics blogs

General blogs.

- [Terence Tao's blog](https://terrytao.wordpress.com/)
- [Timothy Gower's blog](https://gowers.wordpress.com/)
- [Francis Su's blog](https://francissu.substack.com/)

Inverse problems.

- [The Finnish Inverse Problems Society (FIPS)](https://fips.fi/)

Intersting posts

- Terence Tao's post [There’s more to mathematics than rigour and proofs](https://terrytao.wordpress.com/career-advice/theres-more-to-mathematics-than-rigour-and-proofs/) identifies three stages of mathematical education: *the pre-rigorous stage*, *the rigorous stage*, and *post-rigorous stage*.

## Programming blogs

For learning C++.

- [Learn Cpp](https://www.learncpp.com/) is a free website that teaches how to program in modern C++.
- [Raylib](https://www.raylib.com/) is a simple and easy-to-use library to enjoy videogames programming. Can be used with various programming languages. I use it with C and C++.

For graphics programming. I'm mostly interested in learning about graphics programming for video game purposes and for building a game engine.

- [Learn OpenGL](https://learnopengl.com/)
- [Learn Vulkan](https://docs.vulkan.org/spec/latest/index.html)
